# OpenRouteService (ORS) API Sample Payloads

Folder ini menyimpan sampel respon GeoJSON mentah dari OpenRouteService v2 Directions API yang digunakan selama tahap riset & perancangan profil mobilitas navigasi **LELUASA**:

* `foot.json`: Sampel respon profil pejalan kaki umum (`foot-walking`) di koridor Surabaya.
* `wheelchair.json`: Sampel respon profil kursi roda (`wheelchair`) tanpa rintangan.
* `wheelchair-avoid.json`: Sampel respon rute kursi roda dengan perimeter penghindaran poligon rintangan (`avoid_polygons`) pada titik galian utilitas.
